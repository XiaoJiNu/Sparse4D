# Sparse4D 环境安装记录

## 2025-10-21
- `python3 --version` → 3.8.20，确认符合项目要求的 Python 版本。
- `virtualenv mm_sparse4d --python=python3.8` 成功在仓库根目录创建独立虚拟环境。
- `source mm_sparse4d/bin/activate && pip install --upgrade pip`：pip 已为 25.0.1，命令超时但未影响后续使用。
- `source mm_sparse4d/bin/activate && pip install -r requirement.txt`：因镜像源未提供 `torch==1.13.0+cu116` 对应轮子导致失败。
- `source mm_sparse4d/bin/activate && pip install torch==1.13.0+cu116 --extra-index-url https://download.pytorch.org/whl/cu116`：需要访问外网下载官方 CUDA 轮子，当前网络限制导致命令超时终止。
- `source mm_sparse4d/bin/activate && pip install numpy==1.23.5`：同样因网络 DNS 解析失败，无法从镜像站获取包。

### 后续建议
- 在可访问 `download.pytorch.org` 的网络环境下重新执行 PyTorch 相关安装命令，或预先下载对应 whl 文件后使用 `pip install <wheel>` 本地安装。
- 若需继续使用当前环境，请为 `pip` 配置可用的内部镜像或离线包缓存，再执行 `pip install -r requirement.txt`。
- 完成依赖安装后，别忘记在虚拟环境内运行 `cd projects/mmdet3d_plugin/ops && python3 setup.py develop` 编译自定义 CUDA 算子。
