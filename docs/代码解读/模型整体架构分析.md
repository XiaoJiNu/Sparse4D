# Sparse4D 模型整体架构与演进分析

> 参考资料：Sparse4D 原论文（docs/论文/202302_Sparse4D-v1.pdf、202305_Sparse4D-v2.pdf、202311_Sparse4D-v3.pdf）及团队整理的系列文章（docs/论文/Sparse4D系列算法：迈向长时序稀疏化3D目标检测的新实践.md），结合本仓库 `projects/mmdet3d_plugin` 源码说明。

## 1. 背景与发展脉络

### 1.1 从 DETR3D / PETR 到 Sparse4D

多摄像头 3D 检测的发展经历了 **后融合 → BEV 稠密特征 → 稀疏查询** 的路线。DETR3D 和 PETR 率先将 Transformer 查询（query）扩展到 3D 空间，但依赖全局注意力，计算量仍与特征图分辨率强相关。Sparse4D v1（2022 年底）提出：

- 使用 **InstanceBank** 维护显式的 “特征 + 3D anchor state” 组合，区分语义与几何信息；
- 借助 **Deformable Feature Aggregation（DFA）** 在稀疏查询上做跨视角采样；
- 将上一帧的实例投影到当前帧，实现 **纯稀疏的时序建模**。

### 1.2 Sparse4D v2 的效率与泛化优化

Sparse4D v2（2023 年中）针对工程部署做了三点增强：

1. **单帧层 + 时序层解耦**：先用单帧层生成高置信度实例，再交给时序层与上一帧缓存融合；
2. **Efficient Deformable Aggregation**：自研 CUDA 算子将“采样+融合”合并，显存和速度显著提升；
3. **相机内外参编码 + 深度辅助监督**：提升对摄像头参数扰动的鲁棒性，加快稀疏训练收敛。

这些细节在 `projects/configs/sparse4dv3_temporal_r50_1x8_bs6_256x704.py` 中均可见，如 `num_single_frame_decoder=1`、`depth_branch`、`use_camera_embed=True` 等。

### 1.3 Sparse4D v3 的时序鲁棒性

Sparse4D v3（2023 年底）进一步面向 **检测 + 跟踪一体化**：

- 在 Head 中加入 **Denoising（DN）去噪训练** 和 **质量估计分支**（centerness/yawness）；
- InstanceBank 增强了缓存策略与 `instance_id` 维护，为长时序跟踪提供原生支持；
- 采样器 `SparseBox3DTarget` 兼容时序 DN，抑制噪声对最终预测的影响。

本仓库主干即 v3 版本：配置文件默认 `with_quality_estimation=True`、`num_temp_dn_groups=3` 等。

## 2. 总体数据流与模块结构

下表概括了 Sparse4D 推理时的主要数据形态。变量含义均可在 `projects/mmdet3d_plugin/models` 中找到对应实现。

| 阶段 | 关键函数 | 输入形状 | 输出形状 | 说明 |
| --- | --- | --- | --- | --- |
| 图像特征提取 | `Sparse4D.extract_feat` (`sparse4d.py:43-92`) | `img: [B, N_cam, 3, H, W]`，默认 `6×256×704` | `feature_maps[l]: [B, N_cam, 256, H_l, W_l]`，`l=4` | ResNet-50 + FPN，多尺度 256 维特征；可选 depth 分支输出 `[B·N_cam,1,H_l,W_l]` |
| 查询初始化 | `InstanceBank.get` (`instance_bank.py:58-130`) | - | `instance_feature: [B, 900, 256]`<br>`anchor: [B, 900, 11]`<br>`temp_*: [B, 600, •]` | 从可学习参数与缓存中取稀疏实例；`11` 维 state：`x,y,z,log w,log l,log h,sinθ,cosθ,vx,vy,vz` |
| Anchor 编码 | `SparseBox3DEncoder` (`detection3d_blocks.py:21-74`) | `[B, N, 11]` | `[B, N, 256]` | 位置/尺寸/朝向/速度分支编码后相加或拼接，得到位置编码 |
| Transformer 层序列 | `Sparse4DHead.forward` (`sparse4d_head.py:121-359`) | `instance_feature/anchor/...` | 同输入 | 39 个子操作，按 `operation_order` 反复执行 `temp_gnn → gnn → norm → deformable → ffn → norm → refine` |
| Deformable 聚合 | `DeformableFeatureAggregation` (`blocks.py:32-167`) | `instance_feature: [B, N, 256]`<br>`feature_maps` 等 | 输出 `[B, N, 256]` 或 `[B, N, 512]`（`residual_mode='cat'`） | 生成 3D 关键点 → 多视角投影 → 采样（可选 CUDA）→ 权重融合 |
| 框精修与分类 | `SparseBox3DRefinementModule` (`detection3d_blocks.py:79-146`) | `instance_feature + anchor_embed` | `prediction: [B, N, 11]`<br>`cls: [B, N, num_cls]`<br>`quality: [B, N, 2]` | 预测残差并加回 anchor，输出类别和质量（centerness/yawness） |
| 去噪数据 | `SparseBox3DTarget.get_dn_anchors` (`target.py:92-185`) | GT 框/标签 | `dn_anchor` 等拼接 | 生成正负噪声锚点与注意力掩码，训练时并入查询 |
| 解码输出 | `SparseBox3DDecoder.decode` (`decoder.py:12-86`) | 分类/回归列表 | `boxes_3d, scores_3d, labels_3d, instance_ids` | Top-K 选择，尺寸指数化，`atan2(sin,cos)` 恢复航向，附加实例 ID |

## 3. 细节拆解与源码对照

### 3.1 特征提取与辅助监督

- 入口：`Sparse4D.forward_train()` → `extract_feat(img, return_depth=True, metas=data)`。
- 如果 `use_grid_mask=True`，先经过 `GridMask` 增强以提升遮挡鲁棒性。
- `depth_branch` 为可选插件（`DenseDepthNet`），在训练阶段输出深度预测并与 `gt_depth` 计算 L1 损失；推理阶段自动跳过。

### 3.2 InstanceBank：显式稀疏查询与缓存

- **初始化**：`InstanceBank.__init__` 读取 `nuscenes_kmeans900.npy`；`instance_feature` 为 `[900, 256]` 的可学习参数。
- **get 阶段**：
  - 若上一帧缓存存在，`time_interval = metas["timestamp"] - history_time`，并通过 `anchor_handler`（默认 `SparseBox3DKeyPointsGenerator`）结合自车位姿 `T_global`、速度字段，将历史 anchor 投影到当前帧。
  - 返回的 `temp_instance_feature` / `temp_anchor` 供 `temp_gnn` 使用；若缓存为空，函数会触发 `reset()`。
- **update 阶段**：`InstanceBank.update` 从当前预测中挑选高置信度前 `N` 个实例与缓存合并，维持目标数量同时保留去噪样本位置。
- **cache 阶段**：`InstanceBank.cache`（`instance_bank.py:146-210`）在每个迭代末尾存储 `num_temp_instances` 个最可靠的实例特征，并维护 `instance_id` 序列。

### 3.3 Transformer 操作序列

`Sparse4DHead` 在初始化阶段把每种操作映射到 mmcv 注册器（多头注意力、LayerNorm、FFN、自定义插件等）。关键步骤如下：

1. **时序注意力 (`temp_gnn`)**：若存在历史查询，使用 `MultiheadAttention` 对 (`query`, `key=value=temp_instance_feature`) 进行注意力融合，并可选应用 `attn_mask` 隔离噪声锚点。
2. **自注意力 (`gnn`)**：对当前实例间做多头注意力；当 `decouple_attn=True` 时，函数 `graph_model` 会先拼接 `query_pos=anchor_embed` 与实例特征，从而显式注入几何信息。
3. **可变形特征聚合 (`deformable`)**：
   - 生成固定 + 可学习的关键点（`SparseBox3DKeyPointsGenerator.forward`）；
   - 调用 `DeformableFeatureAggregation.forward` 计算权重并采样多视角、多尺度特征；
   - `use_camera_embed=True` 时，还会将投影矩阵编码后与实例特征相加，提升对不同相机布置的泛化能力。
4. **FFN & Norm**：`AsymmetricFFN` 使用 512→1024→256 的两层 MLP，配合 LayerNorm 形成 Transformer Block 的标准结构。
5. **框精修 (`refine`)**：`SparseBox3DRefinementModule` 将预测残差加到 anchor state，并输出分类/质量分支：
   - 尺寸字段 `.exp()` 还原；
   - `atan2(sinθ, cosθ)` 在解码阶段恢复角度；
   - 速度字段根据 `time_interval` 做位移补偿。
6. **单帧 → 时序切换**：当完成 `num_single_frame_decoder` 次 `refine` 后，调用 `InstanceBank.update` 将结果写回缓存，随后时序层继续处理。

### 3.4 去噪训练（DN）

在训练模式下，`SparseBox3DTarget.get_dn_anchors` 会基于真实 GT 生成多组扰动锚点：

- 按 `dn_noise_scale` 对中心、尺寸、角度、速度添加噪声，并构造 `valid_mask`、`dn_attn_mask`；
- 如果 `add_neg_dn=True`，额外添加负样本噪声，提高判别力；
- 返回的 `dn_anchor`、`dn_cls_target`、`dn_reg_target` 会被拼接到实例列表尾部，注意力掩码确保不同噪声组之间互不干扰。

`Sparse4DHead.forward` 在 `refine` 之后拆分正常实例与噪声实例，将去噪预测放入 `dn_prediction`/`dn_classification`。`loss()` 函数调用 `prepare_for_dn_loss`，对有效噪声样本计算额外的分类和回归损失。

### 3.5 解码与跟踪输出

- `Sparse4DHead.post_process` 调用 `SparseBox3DDecoder.decode` 完成最终输出；默认取最后一层结果，进行 Top-K（300）筛选。
- 若 `InstanceBank` 维护了 `instance_id`（推理模式），会直接返回 `instance_ids`，可用于多帧跟踪或提交 nuScenes tracking benchmark。

## 4. 版本演进要点对照

| 版本 | 论文 / 代码特性 | 本仓库体现 |
| --- | --- | --- |
| Sparse4D v1 | 引入 InstanceBank + DFA，首次实现纯稀疏多摄 4D 感知 | `InstanceBank`、`DeformableFeatureAggregation`、基础配置 |
| Sparse4D v2 | 单帧/时序层分离、EDA 自定义算子、相机编码、深度辅助 | `num_single_frame_decoder=1`、`use_deformable_func=True`（需编译 ops）、`use_camera_embed=True`、`depth_branch` |
| Sparse4D v3 | 时序去噪、质量估计、追踪输出、配置统一化 | `sampler.num_temp_dn_groups=3`、`with_quality_estimation=True`、`InstanceBank.get_instance_id()` |

上述演进顺序在 docs/论文 中有更全面的理论阐述，本文档已结合源码提炼出落地细节。

## 6. 实践提示

- **算子编译**：若设置 `use_deformable_func=True`，需执行 `python3 setup.py develop` 以启用 CUDA 版本的 Deformable Aggregation；否则退回 Python 实现但速度会下降。
- **时序缓存**：`InstanceBank.max_time_interval` 控制能否跨帧匹配，长时序场景可适当增大，前提是车速估计准确。
- **去噪配置**：`sampler` 中的 `num_dn_groups`、`dn_noise_scale`、`num_temp_dn_groups` 需与 head 的处理逻辑匹配；若禁用去噪，可将其设为 0 并移除相关 loss。
- **跟踪输出**：推理脚本 `local_test.sh` 默认开启 `tracking_test=True`，会同时输出检测与追踪结果，便于复现论文中 3D MOT 指标。

---

通过上述梳理，可以看到 Sparse4D 以显式稀疏查询为核心，配合高效的多视角采样和实例缓存机制，在多摄像头 3D 检测 / 跟踪任务中取得了兼顾精度与速度的平衡。理解各模块的输入输出及其在源码中的落点，有助于在此基础上开展新任务（如长序列跟踪、增强型去噪）或进行工程优化。
